# Secure Smart Lost & Found

A privacy-preserving lost and found system using Machine Learning,
Computer Vision, NLP, and Cybersecurity.

## Project Goals

- Intelligent lost and found item matching
- Privacy-preserving found-item images
- Ownership verification
- Secure communication between finder and potential owner
- Suspicious claim detection
- Duplicate/fake report detection
- User behavior anomaly detection
- Secure authentication and authorization

## Technology Stack

- Python
- Flask
- SQLite during development
- PostgreSQL for deployment
- Scikit-learn
- PyTorch
- Computer Vision
- NLP
- HTML/CSS/JavaScript
